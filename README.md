# TaskFlow (СРС №10) — Flutter + SQLite (Drift)

Полнофункциональное офлайн-приложение для управления проектами и задачами в мягкой розовой цветовой палитре.

## Быстрый старт
1. Установите зависимости:
   ```bash
   flutter pub get
   ```
2. Сгенерируйте код Drift (`app_database.g.dart`):
   ```bash
   dart run build_runner build --delete-conflicting-outputs
   ```
3. Запустите тесты (более 15 автотестов):
   ```bash
   flutter test
   ```
4. Запустите приложение:
   ```bash
   flutter run
   ```
